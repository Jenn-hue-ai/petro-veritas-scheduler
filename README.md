# Petro Veritas Field Scheduler

These are spreadsheet templates. Open them in Excel on your computer.

## How to open in Excel (Edge / Windows)

1. Open this folder: https://github.com/Jenn-hue-ai/petro-veritas-scheduler
2. Click **Workers.csv**
3. Click the **Download raw file** button (down-arrow icon)
4. In Downloads, double-click the file — it opens in Excel
5. Repeat for Clients.csv, Jobs.csv, Assignments.csv, Time-Off.csv
6. Copy each into one workbook as separate tabs if you want one file
